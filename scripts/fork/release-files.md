## Files

| File                                   | What it is                                                                                                                                                       | How to use it                                                                                                   |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `Flow-X.Y.Z-x86_64.AppImage`           | **Desktop app for Linux x64.** Its own window, starts its own Flow server and updates itself.                                                                    | Download, `chmod +x`, start it.                                                                                 |
| `Flow-X.Y.Z-x86_64.AppImage.sha256`    | Checksum of the AppImage.                                                                                                                                        | `sha256sum -c Flow-X.Y.Z-x86_64.AppImage.sha256`                                                                |
| `latest-linux.yml`                     | Update manifest of the desktop app: version, file and checksum.                                                                                                  | Read by the app's updater, nothing to download.                                                                 |
| `flow-browser-linux-x64.tar.gz`        | **Flow service for Linux x64:** the server, the web UI you open in a browser, and the `flow` command. It contains no browser.                                    | Installed by `install-cli.sh`, `flow update` or the desktop app.                                                |
| `flow-browser-linux-x64.tar.gz.sha256` | Checksum of the service archive.                                                                                                                                 | Checked automatically when installing.                                                                          |
| `install-cli.sh`                       | Linux installer pinned to exactly this version.                                                                                                                  | `curl -fsSL https://github.com/DaRealHansForSure/flow/releases/download/flow-vX.Y.Z/install-cli.sh \| bash`     |
| `flow-browser-win32-x64.tar.gz`        | **Flow service for Windows x64**, used in the browser. It connects to a Brain on another computer and hosts none. Only present when the Windows build succeeded. | Installed by `install.ps1`.                                                                                     |
| `flow-browser-win32-x64.tar.gz.sha256` | Checksum of the Windows service archive.                                                                                                                         | Checked automatically when installing.                                                                          |
| `install.ps1`                          | Windows installer pinned to exactly this version.                                                                                                                | In PowerShell: `irm https://github.com/DaRealHansForSure/flow/releases/download/flow-vX.Y.Z/install.ps1 \| iex` |

To install the newest version instead of this one, follow the
[install guide](https://github.com/DaRealHansForSure/flow/blob/main/docs/user/install.md).
